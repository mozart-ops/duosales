# Calculadora de Planos Duotalk

Calculadora interna para o time de vendas montar propostas: plano, usuários extras, pacotes de templates, módulos (Automações, Agente de I.A.), números adicionais, integração custom, setup e contrato de 6 meses.

Página estática única (`index.html`), sem build. Preços de referência: página "Planos e preços" da Wiki de Vendas no Notion. Para atualizar valores, edite as constantes `PLANS`, `PACKS`, `SETUP` e `P` no script do `index.html`.
